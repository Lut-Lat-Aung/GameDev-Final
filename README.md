# GameDev-Final 🎮

Unity project for the final exam of **Game Design & Development (CSX4515)**.

This repository contains the full Unity project (Assets, ProjectSettings, etc.) used for the course final. It is intended mainly for instructors and classmates to review the implementation and run the game in Unity.

---

## 🎯 Project Overview

**Course:** CSX4515 – Game Design & Development  
**Student:** Lut Lat Aung  
**Engine:** Unity (tested with Unity 6000.0.59f2 / Unity 6)  
**Language:** C#, plus Unity’s built-in ShaderLab / HLSL for materials and effects.

The project demonstrates core game development concepts in Unity, including:

- Scene setup and basic level design 
- UI elements (menus / HUD)

> Note: This is an exam project, so the main focus is on gameplay mechanics, readability of code, and correct use of Unity features rather than production-level polish.

## 🚀 How to Open and Run the Project in Unity

### 1. Open in Unity Hub

1. Open **Unity Hub**.
2. Click **Add project from disk**.
3. Select the cloned **`GameDev-Final`** folder.
4. Open the project with **Unity 6000.0.59f2** (or a compatible Unity 6 version).

### 2. Open the Main Scene

1. In Unity, go to **Project → Assets → Scenes**.
2. Open the main gameplay scene (for example, `MainScene.unity` or similar).

### 3. Play the Game

1. Press the **Play ▶ button** in the Unity toolbar.
2. The game will start in the editor.
